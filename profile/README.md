## Abstractions AS

Abstractions AS is a Norwegian IT consultancy. These are the tools and libraries we share.

### Abstractions Sass Compiler

Compile Sass and SCSS to CSS in Visual Studio and on your build server, without Node.js. Start a project
with Bulma, Bootstrap or Pico CSS in one click, add icon fonts, compile on save and on build.

[Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=abstractionsas.AbstractionsSassVisualStudioExtension)
· [NuGet](https://www.nuget.org/packages/Abstractions.Sass.CIBuild)
· [Documentation and changelog](https://github.com/Abstractions-AS/sass-compiler)

### Libraries

- [property-accessor](https://github.com/Abstractions-AS/property-accessor): a fast wrapper for property access
  that uses compiled delegates rather than `PropertyInfo`.
- [integrations-ssv-veichledata](https://github.com/Abstractions-AS/integrations-ssv-veichledata): looks up
  vehicle information in the Norwegian Vehicle Registry (Statens vegvesen).
